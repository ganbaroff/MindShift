## Чем ты управляешь СЕГОДНЯ (пульт @CreatorBy_bot)

- `/news`, `/ladder` — заказать ролик с телефона → превью с вердиктом гейтов придёт в чат (~15-20 мин)
- `/go` — опубликовать последний прошедший гейты клип; `/status` — очередь; `/stop` — отменить
- Ежедневная лента — сама, без тебя: 08:25 CI → рендер → гейты → публикация

## Чего пока НЕЛЬЗЯ (беклог, честно)

- ❌ **Закинуть СВОЙ сценарий/вопрос с телефона** — v2 пульта (команда `/scenario <текст>` → в JSON → рендер). Сегодня: свой сценарий = правка файла на компе.
- ❌ Менять длительность/темп из бота (константы в коде — закон; правится за минуту, но руками моими)
- ❌ YouTube-публикация; ❌ факт-чекер сценария; ❌ произношение ушами машины

## Best practices мира — что применено / что нет

Применено: поэтапные QA-гейты (n8n-модель «модуль проверяет модуль»), human-in-the-loop перед публикацией (твоё `/go`), идемпотентность, детерминизм (голос/темп/палитра — константы законом, не настроением), fail-closed (сломался гейт → стоп, не пропуск), пруф-линки на каждый артефакт.
НЕ применено (в беклоге): golden-sample регрессия (эталонный эпизод перерендеривается при каждом изменении движка — ловит тихие поломки), алерт в TG при падении CI, факт-чек стадии сценария, канареечная публикация.
